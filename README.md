# Fangyuan Zhao — Academic homepage

Live site: https://zhaofangyuan98.github.io/

A responsive, static academic website hosted with GitHub Pages. No package installation or build is required.

## Editing

- Edit `index.html` to change the introduction, publications or project links.
- Edit `style.css` to change appearance.
- Replace `assets/portrait.jpg` to change the profile image.
- `publications.json` is a structured reference copy of the bibliography; changes to it do not automatically update HTML.

GitHub Pages publishes the root of the `main` branch.
